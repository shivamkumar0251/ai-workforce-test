# Repository Memory

- This project is a small Python application packaged with `pyproject.toml` and `setuptools`.
- Application code lives in `app/`; reusable email validation logic is in `app/validation.py`.
- Command-line execution is available via `python -m app` or the `email-validator` script.
- Automated tests live in `tests/test_validation.py` and run with `pytest`.
